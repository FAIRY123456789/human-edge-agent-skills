# Personal Brand Slop Signals

Common low-signal patterns:

- “AI enthusiast / passionate innovator / full-stack thinker” with no proof nearby.
- Five unrelated identities competing in the first screen.
- Old student CRUD demos above newer externally validated work.
- Technology lists longer than the results section.
- “Production-grade”, “core”, “industry-leading”, “end-to-end”, “0→1” without verifiable scope.
- Decorative GitHub contribution graphs used as a substitute for useful repositories.
- README badges that create visual density but do not help a user run the project.
- Ten project cards with no hierarchy.
- AI-generated abstract hero copy that could describe anyone.
- Trend-chasing keywords that the owner cannot explain in an interview.

## Better signals

- real users or downstream use;
- reproducible demo;
- external review;
- issue/PR activity;
- clear personal responsibility;
- recent release history;
- focused technical writing;
- a coherent path from current work to the target role.
