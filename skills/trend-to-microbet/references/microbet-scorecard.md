# Microbet Scorecard

Score each 0–2.

| Dimension | 0 | 1 | 2 |
|---|---|---|---|
| Real pain | Mostly novelty | Some plausible need | Repeated observable pain |
| Timing | Mature/crowded | Growing | Newly opened capability/platform |
| Personal leverage | Starts from zero | One useful asset | Several existing assets |
| Testability | Weeks before feedback | Feedback in ~1–2 weeks | Feedback in 48h–7d |
| Distribution | No obvious users | One reachable channel | Existing users/community/audience |
| Downside | High cost or lock-in | Moderate | Cheap and reversible |
| Learning value | Narrow | Transferable in part | Useful even if the bet fails |

## Decision heuristic

- 11–14: strong candidate for a microbet.
- 8–10: test only if effort is tightly capped.
- 0–7: watch, do not chase yet.

This is a prioritization aid, not a forecast.
