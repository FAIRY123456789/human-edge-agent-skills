# vibe-to-spec

> **Voice chaos to coding-agent contract**

Resolve recurring ASR errors from active context and turn half-formed spoken ideas into scope, flows, data, constraints, acceptance tests, and an implementation order.

**Category:** Voice Native
**Keywords:** vibe-coding, voice, asr, codex, claude-code, spec

The task described in [`SKILL.md`](SKILL.md) keeps recurring and a generic assistant response would miss the workflow, guardrails, or output contract encoded here.
