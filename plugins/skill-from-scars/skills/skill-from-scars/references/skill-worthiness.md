# Skill Worthiness Score

Score 0–2.

| Dimension | Question |
|---|---|
| Recurrence | Has the pain happened repeatedly? |
| Generalizability | Would other people plausibly face the same structure? |
| Base-model gap | Does a normal agent repeatedly miss something important? |
| Decision procedure | Can the response be expressed as a repeatable sequence or gate? |
| Testability | Can we tell when the Skill improved the outcome? |
| Portability | Can it work without private infrastructure? |
| Distinctiveness | Does it encode a real insight rather than generic advice? |

Prefer candidates scoring 11+ out of 14. Lower scores can remain private notes until more evidence appears.
