# Privacy and data handling

Last updated: 2026-09-08

This plugin is a local instruction package. The publisher operates no service for it and does not collect telemetry, analytics, account information, prompts, drafts, generated content, or usage data.

The plugin does not send content to a publisher-controlled endpoint. Any processing performed by the host is governed by that host's own terms and privacy controls. Users should obtain consent and remove private or confidential details before editing personal or third-party stories.

The plugin is for text editing only. It does not process audio, clone voices, impersonate people, or perform external network actions.

The plugin declares no scripts, MCP servers, hooks, commands, agents, rules, environment variables, secret access, or automatic permissions. It stores only files the user explicitly asks the host to create locally.

Privacy questions and security reports may be opened through the repository's GitHub Issues page.
