# Privacy and data handling

Last updated: 2026-09-08

This plugin is a local instruction package. The publisher operates no service for it and does not collect telemetry, analytics, account information, prompts, project evidence, generated content, or usage data.

The plugin does not send content to a publisher-controlled endpoint. Any processing performed by the host is governed by that host's own terms and privacy controls. Users should remove private repository details, credentials, customer data, and confidential metrics before drafting public material.

The plugin does not publish, create accounts, call a marketplace API, or perform external network actions. Publishing remains an explicit user action outside the plugin.

The plugin declares no scripts, MCP servers, hooks, commands, agents, rules, environment variables, secret access, or automatic permissions. It stores only files the user explicitly asks the host to create locally.

Privacy questions and security reports may be opened through the repository's GitHub Issues page.
