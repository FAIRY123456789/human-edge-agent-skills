# Flagship Launch Plan

The repository contains 18 Skills, but public promotion should begin with a few recognizable pains. “Eighteen Skills” is an inventory; a strong before/after is a product story.

## 1. vibe-to-spec — flagship #1

### Hook

**Your voice is fast. ASR is messy. Coding agents need a contract.**

### 20-second demo

Show a deliberately messy voice transcript with repeated corrections and one context-resolvable homophone. Then show:

- normalized named entities;
- scope / out-of-scope;
- user flow;
- acceptance criteria;
- `Ready for coding agent: YES_WITH_ASSUMPTIONS`.

### Proof target

Ask 5–10 developers to feed real voice dumps into the Skill and then hand the generated spec to a coding agent. Measure how many can begin implementation without another round of requirement clarification.

## 2. social-signal-and-tact — flagship #2

### Hook

**Stop sending your professor a mini government report on WeChat.**

### Demo

Before: generic AI-polished three-paragraph thank-you.

After: one short message using specific credit, actual effect, and a low-friction request.

### Proof target

Blind preference test: which version would a real recipient rather receive? Track “too formal / too flattering / natural / clear request”.

## 3. trend-to-microbet — flagship #3

### Hook

**See a trend. Place a small bet. Demand evidence.**

### Demo

Input: “Everyone is talking about X. Should I spend two weeks learning it?”

Output: verified trend, leverage inventory, 72-hour experiment, 6-hour cap, proof metric, stop rule.

### Proof target

Compare against ordinary AI advice on whether users end with a testable experiment rather than a reading list.

## 4. skill-from-scars — flagship #4

### Hook

**Turn the mistake you made three times into the Skill nobody else has to relearn.**

### Demo

Input three short failure logs. Output: repeated pain, worthiness score, trigger, hard gates, `SKILL.md` scaffold, eval case.

### Proof target

Have users feed actual retrospectives and count how many generated candidates survive manual review as genuinely reusable Skills.

## 5. deep-talk-to-podcast — creator expansion

### Hook

**A two-hour conversation contains more than a summary. Keep the turning points, then make it listenable.**

Best launched after the first four have established the repository identity.

## Distribution rule

Post one Skill at a time. Link directly to its folder inside the monorepo while keeping the repository as the canonical entry point.

Track installs and stars as distribution signals. Track successful task completion, repeat use, issues, PRs and downstream integrations as stronger utility evidence.
