# Virality Without Fake Hype

A “viral” Skill cannot be guaranteed. The repository can maximize the chance of discovery by making the pain immediately recognizable and the result demoable.

Score launch candidates on 0–2:

| Dimension | Question |
|---|---|
| Pain clarity | Can a stranger understand the pain in one sentence? |
| Demoability | Can before/after be shown in under 30 seconds? |
| Distinctiveness | Does the Skill encode more than generic prompting? |
| Youth / current relevance | Does it connect to a current behavior such as voice-first AI, vibe coding, Agent Skills, build-in-public, or creator workflows? |
| External proof | Can a tester objectively say whether it helped? |
| Shareability | Would a user send the result to someone else? |
| Installation friction | Can it be tried without setting up private infrastructure? |

The strongest launch candidates in v0.2 are `vibe-to-spec`, `trend-to-microbet`, `social-signal-and-tact`, and `skill-from-scars`.
