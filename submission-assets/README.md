# Submission Assets

This directory contains review-ready artifacts only. Nothing here proves submission, review, approval, publication, installs, or adoption.

`openai/` contains deterministic Skills-only ZIP archives for the first two OpenAI candidates. Rebuild them with:

```bash
python scripts/build_openai_submission_packages.py
```

Compare the resulting hashes with `openai/SHA256SUMS.txt` before a future manual upload.
